# 使用 Vite 搭建 React 项目

这是一篇示例文章，后续将接入完整的 Markdown 渲染。

## 为什么选择 Vite

Vite 提供了极快的开发服务器启动和热模块替换（HMR）。

## 快速开始

```bash
npm create vite@latest my-app -- --template react-ts
cd my-app
npm install
npm run dev
```

## 总结

Vite 是现代前端项目的最佳选择。
